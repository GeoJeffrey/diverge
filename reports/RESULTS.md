## Resume bullets generated from these results

Each bullet uses only the numbers above. Pick 3-4 and lead with the strongest.

- Fine-tuned/benchmarked financial sentiment models on 2,388 held-out finance tweets; best model (FinBERT fine-tuned on finance tweets) reached 0.85 macro-F1 vs 0.44 for the keyword baseline (1.9x).
- Domain-adapted FinBERT to social media text: macro-F1 0.67 → 0.85 (+18 pts), 1,427 texts/sec inference.
- Built a coordinated-posting (bot campaign) detector and a ground-truth benchmark of 4,000 simulated windows / 491k posts; replaced a hand-tuned score (ROC-AUC 0.66, 0.5% recall) with a learned scorer reaching ROC-AUC 0.96, F1 0.92 (93% precision / 91% recall).
- Implemented MinHash + LSH near-duplicate detection from scratch: 40x faster than exhaustive search on 4,000 posts with 100% pair recall.
- Showed social-media narrative features add out-of-sample information beyond prices: next-day volatility forecast error reduced 5.4% vs a HAR baseline (Diebold-Mariano p<0.001) in a walk-forward backtest over 6,320 ticker-days / 1.7M posts.
- Built a big-move early-warning model: days it flagged were followed by a large price move 2.26x more often than average (30% vs 13% base rate; price-only model 1.78x), out-of-sample over 5,055 ticker-days.
- Found next-day volatility is 1.6x higher after social-attention shocks (95% CI 1.47-1.80).
- Shipped an explainable next-day outlook (direction + expected move) with a public track record: 'bigger move than usual' calls were right 49% of the time vs a 39% base rate (1.26x lift) over 5,055 out-of-sample ticker-days.
- Served analytics through a JWT-secured FastAPI + PostgreSQL backend at p95 ≤ 245 ms and 152+ req/s under 32 concurrent clients.
